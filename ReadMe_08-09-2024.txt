Route 53
Cloud DNS web service offerred by AWS. It is designed to route end user requests to internet
applications, websites or any other service. It also allows you to register domain name.

1. Domain name registration
2. DNS Management: translates human-readable domain names into IP addresses
3. Traffic Routing Policy: https://docs.aws.amazon.com/Route53/latest/DeveloperGuide/routing-policy.html

Amazon Fsx: managed service from AWS that provides scalable file systems for variety of user
            cases such as storage for databases, big data analytics, machine learning, content
			management
1. Amazon Fsx for windows File server: Suitable for windows based workloads
2. Amazon FSx for Lusture: High performance file system optimized for compute intensive workloads.
                           It is often used for HPC workloads
3. Amazon Fsx for NetApp ONTAP: widely used in on-premises data centers for storing and managing
                                data
4. Fsx for OpenZFS: Advanced features like data integrity checking, snapshots and efficient data 
                    compression

EFA vs ENA vs ENI: Are used in context of EC2
ENA : Elastic Network Adapter: Default high-performance network interface used by EC2 instances
      for providing enhanced networking features. Supports network speed upto 10gbps
EFA: Elastic Fabric Adapter: Designed for Machine learning workloads. It provides low latency 
     networking and enhanced support for parallel computing
ENI: Elastic Network Interface: Virtual network interface. provides standard network capabilities.
